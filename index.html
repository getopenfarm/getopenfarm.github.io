Run OpenFarm on your server

One Docker Compose stack: OpenFarm and PostgreSQL, on a Linux host with LAN access to the printers.

  1. Get the Compose filesdocker-compose.yml and .env from the repository.
  2. Set passwordsDatabase and first administrator, in .env. Publish Postgres on 127.0.0.1, as in the guide.
  3. Start the farmOpen http://<server-ip>:6868. Add the first printer.

Before you install

Which printers can I connect?

Bambu Lab X1, X1 Carbon, X1E, P1P, P1S, A1 and A1 mini, in LAN mode. Snapmaker U1, through Moonraker. OpenFarm supports a model only after the model is in the catalog.

Supported printers
Where does OpenFarm run?

One OpenFarm instance with PostgreSQL, on a Linux/amd64 server with LAN access to the printers. The team uses OpenFarm in a browser.

Installation requirements
Does OpenFarm clear the bed?

No. Inspect the print. Clear the bed. Mark the printer ready. The next matching plate then starts.

Quick start
Can I print fixed batches and repeat stock?

Yes. A run makes a fixed quantity of parts or complete sets. Continuous backfill prints repeat stock on idle, compatible printers after the fixed work.

Continuous backfill
Is OpenFarm free?

Yes. OpenFarm is open source under AGPL-3.0, with no fee per printer or seat. Read the license before you modify or distribute OpenFarm.
